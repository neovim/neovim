                            NVIM REFERENCE MANUAL


Builtin plugin: tar                                                      *tar*

Nvim opens a read-only listing when |:edit| is used with a tar archive. The
listing is a |dir| buffer with 'filetype' set to "tar"; entries open as
read-only `nvim-tar://{archive}/{path}` buffers. Requires the `tar`
executable.

Recognized extensions include tar, tgz, tbz, txz, tzst, tlz4, cbt, and lrp,
along with the `tar.*` compressed forms.

Compressed archives are decompressed by `tar` itself rather than by a separate
tool per format, which requires GNU tar 1.15 or newer, or bsdtar. Whichever
formats the installed `tar` was built without remain unreadable.

                                                    *g:loaded_nvim_tar_plugin*
To disable the built-in tar browser, set this before startup: >lua

    vim.g.loaded_nvim_tar_plugin = 1
<
MAPPINGS                                                       *tar-mappings*

The standard |dir-buffer-mappings|.

At the archive root, - opens the containing filesystem directory.

LIMITATIONS                                                *tar-limitations*

Archive entries cannot be updated or extracted, and there is no |:TarDiff|
equivalent, no custom backend command, and no support for the legacy
`g:tar_*` variables. Use |old-tar| when those features are required.

A tar archive has no central directory, so every entry read rescans the
archive, and a compressed archive is decompressed from the start each time.

bsdtar treats an entry name as a glob, and GNU tar's `--no-wildcards` has no
bsdtar equivalent, so an entry whose name contains `*` or `?` may match
several. Such an entry is reported as ambiguous rather than read.

==============================================================================
Legacy plugin: tar                                                   *old-tar*

The legacy Vimscript tar plugin browses, updates, and extracts archive
entries. It is not loaded by default; use `:packadd` to activate it: >lua

    vim.cmd.packadd('old-tar')
<
This can be done at any time. Its manual is then available as
`:help pi_tar.txt`.
