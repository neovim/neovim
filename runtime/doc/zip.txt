*zip.txt*    Nvim


                            NVIM REFERENCE MANUAL


Builtin plugin: zip.lua                                               *zip.lua*

zip.lua is the default, read-only browser for zip archives. It uses the builtin
|dir| listing interface and requires the `unzip` executable. The module
implementing zip.lua is private and is not a supported Lua API.

                                                    *g:loaded_nvim_zip_plugin*
To disable the built-in zip browser, set this before startup: >lua

    vim.g.loaded_nvim_zip_plugin = 1
<
ARCHIVE LISTINGS                                           *zip.lua-listing*

Editing a zip-like file opens a read-only listing. Directory entries can be
opened to browse that level of the archive. File entries open as read-only
`zipfile://{archive}::{member}` buffers.

Mappings:                                                   *zip.lua-mappings*
>
    <CR>    Open the file or directory under the cursor.
    -       Open the parent archive directory.
    R       Reload the current archive directory.
<
At the archive root, "-" opens the containing filesystem directory.

zip.lua recognizes the same zip-like extensions as the legacy plugin, including
`zip`, `jar`, `apk`, `epub`, Office/OpenDocument formats, `whl`, `xpi`, `pkpass`,
and `cbz`.

INTEGRATIONS                                          *zip.lua-integrations*

Remote zip URLs are downloaded by |vim.net| and opened in the browser.

|g:ftplugin_java_source_path| opens the selected member with |gf|.

LIMITATIONS                                               *zip.lua-limitations*

zip.lua does not update or extract archive members. It does not refetch remote
archives on reload or support PowerShell fallback, custom backend commands, or
the legacy `g:zip_*` configuration variables. Use |package-zip| when those
features are required.

==============================================================================
Legacy plugin: zip                                                *package-zip*

The legacy Vimscript zip plugin browses, updates, and extracts archive members.
It is not loaded by default; use `:packadd` to activate it: >lua

    vim.cmd.packadd('zip')
<
This can be done at any time. Its manual is then available as
`:help pi_zip.txt`.
